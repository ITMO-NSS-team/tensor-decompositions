## Границы приёмки

Локальная среда: Windows, Python 3.10, PyTorch 2.2.0, NumPy 1.26.4, TensorLy 0.9.0, CPU. Дополнительные профили CI указаны в `.github/workflows/ci.yaml`; они считаются выполненными только после успешного удалённого запуска.

Проверки устанавливают численные и программные контракты. Они не подтверждают качество обучения LLM, универсальное ускорение, новую научную гипотезу, поддержку всех GPU/распределённых конфигураций или интеграцию в непроверенный потребительский репозиторий. Старые checkpoints с экземплярами проекторов не загружаются автоматически; выдаётся явная ошибка версии. Для пользовательских SVD-callable переносимое сохранение поддержано только после перехода к зарегистрированному имени.

Основной агент независимо проверил изменения и воспроизвёл общий набор тестов. Найденные при проверке ошибки — удержание полного SVD через срезы, заголовок NPY с огромной формой, неполные моменты оптимизатора, смешение поколений checkpoint и фильтр Tikhonov при малой lambda — исправлены вместе с регрессиями.

Для закрытия #63 требуется принять предметные исправления и отдельно разрешить оставшиеся критерии поставки. Пока текст LICENSE не получен, #37 и лицензионный пункт #63 остаются открытыми. Состояние остальных старых задач и предложение по их закрытию приведены в отдельном отчёте об оставшихся issues.

## Итоговая локальная проверка

Общий набор: 496 тестов пройдены, один настоящий TensorFlow-тест пропущен из-за отсутствия зависимости. Отдельно проверен отказ неверных рангов при `python -O`. Собраны wheel и sdist, метаданные сопоставлены; установленный пакет и все его модули импортированы вне исходников. CPU-протокол: шесть записей, ноль отказов, три метода на двух формах матриц, RSS измерен в отдельных процессах. Пользовательские классы Tucker-разложителей явно отклоняются при переносимом сохранении вместо неявной замены на HOOI.

Проверка наличия утверждённой лицензии остаётся невыполненной; CI намеренно запрещает выпуск без неё. Удалённые результаты CI следует проверять отдельно в PR.
