# Оставшиеся задачи: актуальность и порядок закрытия

Основа проверки — открытые issues ITMO-NSS-team/tensor-decompositions, повторно полученные после создания PR #64 2 октября 2026 года, и код ветки release-0.3 с исправлениями аудита. Это проверка репозитория TDEcomp: реализации и состояние FedCore, GOLEM, SamplingZoo и IndustrialTS отдельно не проверялись. Отсутствие их классов здесь не означает, что работы не выполнены в другом проекте.

Исправления опубликованы в [PR #64](https://github.com/ITMO-NSS-team/tensor-decompositions/pull/64) для `release-0.3`. После создания PR открыты 39 issues: 27 задач аудита, сводный #63 и 11 других задач. Issues пока не закрывались. Лицензионная часть #37 остаётся заблокированной; удалённый CI на момент проверки выполняется. Таблица покрытия: [ISSUE_COVERAGE.md](ISSUE_COVERAGE.md).

## Граница исправлений

Задачи #28 и #37–#62 относятся к предыдущему аудиту. Их готовность оценивается по отдельной таблице покрытия и проверкам PR. Они сохраняют состояние OPEN до принятия изменений; наличие PR само по себе не означает закрытие. #63 — сводный план, который следует завершать после проверки всех его критериев. Нельзя автоматически закрывать его по числу изменённых файлов.

Другие открытые задачи перечислены ниже. Краткие формулировки не подменяют оригинальные требования. Задачи потребителей предлагается перенести в репозиторий фактической реализации с сохранением ссылки и истории; перенос и закрытие в этом отчёте не выполняются.

## Сводные планы

[#9 ОБЩИЙ ПЛАН](https://github.com/ITMO-NSS-team/tensor-decompositions/issues/9) смешивает TDEcomp и FedCore. Его пункты о градиентных проекциях, RP-HOSVD и едином интерфейсе можно отметить как реализованные только после принятия PR и проверки оговорённого профиля. Это не закрывает повороты активаций, Positional encodings, прунеры, адаптеры attention и LLM-оценку. Рекомендуется превратить карточку в индекс независимых задач с владельцем репозитория и проверяемым результатом каждого пункта. Содержимое внешней таблицы экспериментов в этой проверке не изучалось.

[#63 План аудита](https://github.com/ITMO-NSS-team/tensor-decompositions/issues/63) следует сверить с таблицей покрытия PR. Критерии, требующие проверки лицензии, дополнительных профилей или внешних потребителей, нельзя подменять локальными тестами NumPy/PyTorch. После принятия выполненных задач отметить только подтверждённые пункты и отдельно оставить непроверенные ограничения.
