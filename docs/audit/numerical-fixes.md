# Численные исправления аудита release-0.3

Исправлены численные замечания #28, #39–48, #57 и #58; из #60 — функциональные обёртки, реестры операций и `ModalDecomposition.compose`. Ошибки комплексных проекторов и оптимизатора из #48 исправляются отдельно в `grad_proj`.

Поддержанный профиль разложений и матричных решателей: NumPy и PyTorch, `float32`, `float64`, `complex64`, `complex128`. Размеры должны быть непустыми, значения — конечными. Неподдержанные типы данных отклоняются до расходования случайного состояния. Проверки выполнены на CPU с Python 3.10, NumPy 1.26.4, PyTorch 2.2.0 и TensorLy 0.9.0. Проверок GPU и обучения не проводилось; TensorFlow отсутствует.

Ранг имеет явную семантику. Положительный целый ранг ограничивается размером развёртки. Дробный ранг из `(0,1]` применяется к размеру исходной моды, округляется вниз с минимумом 1, затем ограничивается максимальным рангом развёртки. Для Tucker предел равен `min(I_n, product(I_other))`. Значение `self.rank` сохраняет исходную настройку. Полный вызов на 9×2 возвращает ядро 2×2 и факторы 9×2,2×2. Избыточные относительно других целевых рангов размеры ядра допускаются; ортогональные дополнения и нули сохраняют объявленные формы. Проверены нормализация при повторном вызове, её идемпотентность и ранги `(3,1,1)`/`(1,3,1)`.

Нормировка генераторов задаётся отдельно. `normal` имеет дисперсию `1/k`, `sparse_iid_entries` — значения `±sqrt(s/k)` с вероятностью `1/(2s)` каждого знака. `ortho` создаёт ортонормированный базис; уменьшенная правая проекция является сжатием без масштабирующего множителя. `identity_copies` разрешён только при `k>=d` и делимости k на d: это изометрическое расширение. GF(256)-вариант ограничен 256 позициями: четыре разные точки поля образуют обратимое отображение Вандермонда для четырёх коэффициентов, а ненулевая двоичная линейная функция даёт независимые равновероятные знаки. Старая реализация `lean_walsh` не соответствовала заявленной конструкции; вариант исключён из поддержанного реестра и явно возвращает `NotImplementedError`. Универсальная JL-гарантия для всех генераторов и параметров не заявляется.

Выбранный RSVD сохраняет случайный поиск подпространства, а точная SVD применяется только к малой проекции. Матрица Грама не формируется: это устраняет ухудшение обусловленности и лишний квадратичный буфер. Стоимость плотного поиска — порядка `(2*power+1)*m*n*(rank+oversampling)` операций, память базиса и проекции линейна по размерам матрицы и ширине выборки. Это описание стоимости, а не измеренное ускорение. Для псевдообратной полная тонкая SVD выбрана вместо нормальных уравнений, поскольку корректно обрабатывает вырожденность.

`distortion_factor` управляет эвристикой автоматического ранга и не гарантирует относительную ошибку. CUR с выбором наиболее важных строк и столбцов не обещает глобально оптимальную ошибку; точное восстановление требует сохранения ранга выбранного пересечения. HOOI ограничивает число итераций и не гарантирует глобальный минимум Tucker.

Квадратный conditioner должен иметь тот же тип данных и устройство, что и матрица. При conditioner спектр относится к XC, исправленный правый фактор может быть неортонормирован, а целевой нормой сокращённого разложения служит взвешенная ошибка `||(X-Xhat)C||_F`. Способ приближения определяется выбранным алгоритмом. Оптимальность обычной SVD исходной X не заявляется. Полный ранг и разрешённый C сохраняют реконструкцию X.

`random_state` принимает целое число, NumPy `Generator` или `RandomState`. Целое число создаёт поток при создании экземпляра; переданный объект расходуется на месте. `None` сохраняет общий поток NumPy. `Projector` владеет `P` и потоком: `renew=True` генерирует следующую матрицу, `renew=False` повторно использует P только при совпадении стороны, размеров, типа данных, устройства и настроек. Состояние сохраняется стандартными средствами NumPy; для продолжения с готовой проекцией дополнительно сохраняется P. Повторяемость относится к закреплённому окружению и численному допуску; побитовое совпадение CPU/GPU не обещается.

`svd_solver_tikhonov` решает `min ||Ax-b||² + lam²||x||²`. При `lam=0` возвращает пороговое решение наименьших квадратов. По умолчанию возвращается один вектор, а превышение допуска невязки сопровождается `RuntimeWarning`. `return_info=True` возвращает решение и поля `converged`, `residual_norm`, `threshold`, `lambda`, `iterations`, `reason`. `maxiter` сохранён ради совместимости и должен быть положительным; закрытая формула вычисляется один раз. Пользовательская SVD обязана быть полной тонкой SVD: проверяются формы, типы, устройство, ортонормированность, конечный упорядоченный неотрицательный спектр и восстановление A в пределах точности типа. Непредставимый результат отклоняется с `ArithmeticError`.

CG применяется к SPD/HPD-системам. При исчерпании итераций обычный вызов выдаёт `RuntimeError`; `return_info=True` возвращает решение, историю истинной невязки и диагностику неуспеха. Вызываемые операторы сохраняют форму, тип данных и устройство вектора. Матричные операторы проверяются на конечность и эрмитовость, положительная кривизна контролируется во время итераций. Допуск `tol` абсолютный, `rtol` — относительно нормы правой части.

Проверки находятся в `tests/test_numerical_regressions.py`, `tests/test_base.py`, `tests/matrix/` и `tests/tensor/`. Использованы независимые NumPy/PyTorch-эталоны и свойства реконструкции, ортонормированности, нормировки, сохранения состояния и четыре тождества Мура — Пенроуза. В float64 основные допуски равны `1e-12`–`1e-10`; для float32/complex64 допускается ошибка порядка `1e-6`. Сравниваются реконструкции и пространства, а не знаки отдельных сингулярных векторов.
