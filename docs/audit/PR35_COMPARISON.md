# Сравнение PR #35 и исправлений аудита

Проверка выполнена 2 октября 2026 года. Исходные ревизии: [PR #35](https://github.com/ITMO-NSS-team/tensor-decompositions/pull/35), `experiment` / `e1b78d44db608e22b56b7b9e61b06a2a1794d494`, относительно `tensorly-ref`; [PR #64](https://github.com/ITMO-NSS-team/tensor-decompositions/pull/64), `codex/audit-fixes-release-0.3` / `928113304f439e2484fcd306e336c0b639e78e74`, относительно `release-0.3`.

PR #35 не устарел целиком. Его исправления фабрик и инструменты экспериментов не были заменены аудитом. Актуальные части перенесены в PR #64 с адаптацией к исправленному ядру. Старые отладочные вмешательства и исторические выводы ноутбуков не выданы за рабочий код и новые измерения.

Скалярный `rank=2` и одноэлементные последовательности продолжают работать: низкоранговый ранг равен 2, а доля разреженной ветви берётся из настройки (по умолчанию `0.25` для `ParallelTG`, `0.1` для `ULTG`). Буквальный перенос скалярной обработки PR #35 превратил бы целый ранг 2 в недопустимую долю 2. Пара сохраняет смысл `(low_rank, sparse_ratio)` из исправлений PR #35; явные параметры соответствующих ветвей имеют приоритет.

## Проверка перенесённого поведения

```bash
python -m pip install '.[test,experiments]'
python -m pytest tests/grad_proj/test_prepared_experiment_presets.py tests/test_experiment_helpers.py -q
python -m examples.tensorgrad_train --steps 3 --seed 17 --output tensorgrad-training.json
```

Проверки используют настоящий PyTorch, Pandas и Matplotlib. Критерии: размеры обеих проекций, сохранность входного градиента, скалярная совместимость, ошибки долей, траектория AdamW, независимый эталон перплексии, восстановление режимов модулей, память проекторов, повторные точки метрик, страницы выдачи, произвольные индексы и повторяемость CPU-запуска. Для адаптеров обратных вызовов дополнительно требуется Transformers из профиля `training`; клиент и приёмник метрик в модульных тестах записывают вызовы без внешнего сервиса.

Локальная проверка на Windows / Python 3.10 / PyTorch 2.2 / NumPy 1.26.4 / TensorLy 0.9: 541 тест пройден, один TensorFlow-тест пропущен из-за отсутствия зависимости. Проверки адаптеров выполнены прямыми вызовами с установленным Transformers 4.39; поддерживаемый профиль Transformers 4.46–4.x проверяется отдельным шагом CI. CPU-пример выполнил три успешных сравнения. Собраны wheel и sdist, метаданные прямого wheel и wheel из sdist совпали; установленный пакет проверен вне исходников. Примеры и контейнерные файлы присутствуют в sdist; пример успешно запущен из распакованного архива.

Пример обучает малую модель на синтетических последовательностях. Он проверяет исполнение и воспроизводимость сценария, но не доказывает качество обучения внешней языковой модели или преимущество TensorGRaD. В отчёте раздельно записаны время обучения и размер тензорного состояния; размер состояния не назван пиком памяти процесса. GPU, внешний MLflow и полное обучение на исходных моделях не проверялись. Конфигурация Compose проверена; служба Docker недоступна, поэтому образ не собирался и не запускался.

PR #35 оставлен открытым как источник и история экспериментов. Перенесённые изменения следует принимать через отдельный коммит PR #64; старую ветку `experiment` не следует сливать поверх исправленного ядра без повторного сравнения. Исторические выводы ноутбуков сохраняют своё исходное значение и не являются результатами этой проверки.

Перед публикацией коммит перенесён поверх `318c813d6a9ae1610ad80aa386a5475e8052d4ca`, который уже включал новые изменения из PR #21 и #36. Конфликтов не возникло; окончательный полный набор — 695 успешных тестов и один пропуск TensorFlow. Сборка и проверка установленного пакета повторены для объединённого состояния.
