# TensorGRaD: исправления задач #49–56

Проверенный профиль: один процесс, CPU, PyTorch 2.2.0, TensorLy 0.9.0, NumPy 1.26.4. Плотные параметры и градиенты: float32/float64 и complex64/complex128. Для обычной ветви комплексные моменты соответствуют действительному представлению PyTorch AdamW. Малая тензорная проекция использует настоящий `HOOIDecomposition`; подмена TensorFlow при импорте не требуется.

## Контракты и принятые решения

`OptimizerConfig` и фабрика оптимизаторов проверяют настройки до создания состояний. `sgd` создаёт `torch.optim.SGD`, `adamw` — `torch.optim.AdamW`; `tensorgrad` и `tensorgrad_sum` создают последовательные и параллельные ветви TensorGRaD. Неподдержанный `lamb` отклоняется явно. Подготовленные `ParallelTG` и `ULTG` возвращают пару «оптимизатор, расписание». Все обучаемые параметры включаются ровно один раз. Проекции применяются к параметрам с двумя и более осями; `exclude_first_parameter=True` помещает первый параметр в обычную группу AdamW, сохраняя его обучение.

`projection_mode="single"` задаёт одну ветвь, `"composite"` — две. Порядок проекторов сохраняется из конфигурации: абсолютный ранг не сравнивается с долей маски. Строковое имя SVD разрешается явно; `full_svd` использует точное SVD с усечением нужных базисов. Зарегистрированная функция TensorLy имеет переносимое имя. Произвольный вызываемый объект работает при вычислении, но сохранение его в переносимый формат отклоняется заранее.

Все проекторы реализуют `project_back(x, output_buffer=None, alpha=1, accumulate=False)`. Результат умножается на `alpha` и масштаб проектора. Переданный буфер целиком заменяется при `accumulate=False` либо получает прибавку при `True`. Неподходящие форма, тип данных или устройство буфера отклоняются. Последовательная вторая ветвь получает `g - first.project_back(first.project(g))`; оптимизатор сохраняет исходный `p.grad`.

Разреженные проекторы сохраняют `ceil(ratio * size)` уникальных индексов. Доля должна лежать в (0, 1]; пустой вход отклоняется. Для структурной маски скалярная доля распределяется поровну по неединичным осям до округления; список задаёт отдельные доли осей. Фактическая доля вычисляется по выбранным координатам. Транспонированные тензоры поддержаны. Для `probability` используются неотрицательные нормы с малой положительной добавкой, поэтому выбор без возвращения определён и для нулевых срезов.

Масштабирование маски имеет три режима:

- `none`: выбранные координаты сохраняют исходные значения при `scale=1`.
- `energy`: множитель `1/sqrt(p)` сохраняет ожидаемую квадратную норму для равномерной маски. Среднее восстановление равно `sqrt(p) * g`.
- `unbiased`: множитель `1/p` даёт среднее восстановление `g` для равномерного `randk`. Для `topk` и `probability` этот режим отклоняется.

Здесь `p` — фактическая вероятность включения координаты. Для структурной равномерной маски это произведение долей выбранных индексов осей. Прежнее `scale_by_mask_ratio=True` выбирает `energy`; поле больше не меняется скрыто после первого шага. `lambda_sparse` — буквальный неотрицательный вес разреженной ветви; скрытая эвристика отношения степеней свободы и особое значение 5.5 удалены.

Единственная принятая политика моментов — `moment_policy="reset"`. Каждое запланированное переобучение базиса или маски сбрасывает оба момента и счётчик поправки на смещение соответствующей ветви. Это консервативная политика: сброс происходит и при повторном получении совпадающих координат. Явное `reset_sparse_optimizer_states=False` отклоняется как противоречие политике. Поворот только покомпонентного второго момента не выдаётся за перенос ковариации.

Фиксированное расписание интервала k обновляет проекцию на шагах 0, k, 2k. Каждый экземпляр владеет своим расписанием и генератором случайности. Поддержаны `fixed`, `linear`, `cosine`, `step`, `exponential`, `exponential2`; горизонт положительный, прогресс ограничен [0, 1]. Состояния расписания и генератора сохраняются. Все объявленные расписания скорости обучения имеют `step`, `state_dict` и `load_state_dict`.

Обычная ветвь TensorGRaD с `correct_bias=True` соответствует PyTorch AdamW: epsilon применяется после коррекции второго момента, затухание весов — до добавления обновления. `correct_bias=False` явно выбирает вариант без поправки на смещение. Составная проекция, масштабы и веса ветвей задают отдельный метод; для него не заявляется равенство обычному AdamW. Функция `closure` исполняется с включёнными градиентами и возвращает loss. Исключение из неё возникает до шага обновления оптимизатора.

## Состояния и границы совместимости

Пользовательский `tensor_decomposer_type` можно использовать для вычислений, но его сохранение в переносимый формат отклоняется явно. Для тензорного проектора этот формат поддерживает только `HOOIDecomposition`; загрузка не заменяет пользовательскую реализацию молча.

`TensorGRaD.state_dict()` содержит версию 1, все флаги метода, группы, моменты, отдельные счётчики ветвей и обычные данные проекторов. Сохранение и чтение через `torch.load(..., weights_only=True)` проверены. При загрузке проекторы создаются через закрытый реестр; все вещественные или комплексные буферы приводятся к типу данных и устройству параметра, индексы сохраняют целочисленный тип. Неизвестная версия, неполные пары моментов, неверные размеры и недопустимые индексы отклоняются до изменения оптимизатора. Старые состояния с объектами проекторов в pickle не принимаются автоматически.

`save_training_state` использует стандартный протокол `state_dict/load_state_dict` модели, оптимизатора, расписания и регуляризатора. Каждый компонент может отсутствовать. `epoch=None`, 0 и положительное целое число имеют явный смысл. Результат загрузки — `TrainingState`, именованный кортеж из пяти прежних позиций. Если необязательный компонент не записан, переданный объект остаётся без изменений; сохранённый компонент можно пропустить, передав None.

Один каталог содержит одну активную контрольную точку. Новые файлы компонентов имеют уникальное имя поколения; новый `manifest.pt` публикуется последним через атомарную замену. Прерванная запись оставляет прежнюю полную точку доступной. Проверка всего манифеста и файлов предшествует восстановлению; ошибка загрузки компонента откатывает все переданные состояния. Формат сохраняет случайность Python, NumPy и Torch на CPU. Он не инициализирует CUDA. Старый нестандартный протокол `save_checkpoint/from_checkpoint`, неизвестные версии и распределённая загрузка отклоняются явно.

Асинхронный распределённый модуль и профилировщик импортируются в базовом окружении. Их необязательные API загружаются при вызове; отсутствие нужной версии PyTorch или CUDA диагностируется явно. Продолжение на GPU, распределённое обучение и качество обучения этим набором CPU-проверок не подтверждены.

## Выбор алгоритмов и ресурсные ограничения

Сохранены плотные сжатые моменты и явный сбор/расстановка вместо маскированных полных моментов. Низкоранговые базисы копируются после усечения, поэтому они не удерживают полное хранилище результата SVD. Остаток вычисляется в отдельном полном тензоре: это делает владение памятью однозначным и сохраняет наблюдаемый градиент. Восстановление также может выделять полный временный тензор. Отказ от этой памяти потребовал бы отдельной проверки операций с перекрывающимися буферами.

Для равномерного выбора используется полная случайная перестановка; для topk — стабильная сортировка с определённым порядком равных оценок. Это простые эталоны корректности, а не подтверждённая оптимизация больших моделей. GPU, скорость, пиковая память, качество обучения и сходимость не измерялись. При необходимости ускорения следует отдельно сравнить отбор topk и выборку без полной перестановки, сохранив уникальность, порядок, локальную случайность и воспроизводимость.
