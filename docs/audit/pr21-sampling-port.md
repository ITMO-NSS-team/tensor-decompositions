# Перенос выборки столбцов из PR #21

PR #21 (`sampling-techniques`, `7db0096`) сравнивался с PR #64 после исправлений
аудита (`9281133`). Полезная часть старого PR — два самостоятельных метода
выборки столбцов и разложение по выбранным столбцам — отсутствовала в PR #64.
Она перенесена с исправлениями в `tdecomp.matrix.sampling_techniques`.

| Часть PR #21 | Решение |
| --- | --- |
| `BaseSketch` | Реализованы `sketch`, вызов объекта и разложение `(C, pinv(C) @ A)`. Размер проверяется по правилам текущего API. |
| `AdaptiveSamplingSketch` | Веса относятся к столбцам: они вычисляются по оценке правого сингулярного вектора. Выбираются разные столбцы. |
| `ColumnSelectSketch` | Веса вычисляются по правому подпространству; нулевые направления исключаются. Выбираются разные столбцы. |
| Новый абстрактный `_decomposition_error` | Не перенесён: в старом PR он делает существующие классы разложений абстрактными без реализаций этого метода. |
| Автоматический ранг CUR по допуску | Не перенесён: бинарный поиск предполагает монотонность ошибки, которой выборка строк и столбцов с псевдообратной матрицей пересечения не гарантирует. |
| Изменение эвристики ранга | Не перенесено: выражение `min(..., 1)` в PR #21 ошибочно ограничивает результат единицей. В PR #64 ранг уже проверяется и вычисляется корректно. |

Оба метода используют эвристические случайные оценки. Названия классов
сохранены, но они не обещают гарантий опубликованных алгоритмов
adaptive sampling или ColumnSelect. `power_iterations` задаёт число проходов
через `A` и `A.H`; матрица масштабируется перед вычислениями.
`epsilon` сохранён для совместимости и проверяется, однако не меняет размер
выборки и не задаёт гарантированную ошибку.

`sketch_size` — положительное целое число или доля в `(0, 1]` от меньшей
размерности матрицы. По умолчанию используется `compression_ratio` в `(0, 1)`.
Если ненулевых весов меньше требуемого числа столбцов, остальные выбираются
из столбцов с нулевыми весами. Нулевая матрица допускает равномерную выборку.
`column_indices` хранит выбранные индексы; `random_state` управляет отдельным
потоком случайных чисел по правилам остальных классов библиотеки.

```python
from tdecomp.matrix.sampling_techniques import ColumnSelectSketch

sampler = ColumnSelectSketch(sketch_size=3, random_state=42)
C = sampler.sketch(A)
C, coefficients = sampler.decompose(A, random_state=42)
approximation = sampler.compose(C, coefficients)
```

Проверки сравнивают коэффициенты с независимым решением `numpy.linalg.lstsq`,
а веса для комплексной матрицы ранга 1 — с известными весами её столбцов.
Также проверяются прямоугольные матрицы, нулевые и зависимые столбцы,
изменение формы при повторном вызове, воспроизводимость, сохранность внешних
генераторов случайных чисел и раннее отклонение неверных параметров.
Проверки выполнены на CPU; выполнение на GPU не проверялось.
Общий запуск `python -m pytest -q` завершился результатом `572 passed, 1 skipped`.
Дополнительная проверка обоих методов на NumPy и PyTorch с типами `float32`,
`float64`, `complex64` и `complex128` подтвердила конечность коэффициентов,
сохранение типа данных и точное совпадение выбранных столбцов с входными.
